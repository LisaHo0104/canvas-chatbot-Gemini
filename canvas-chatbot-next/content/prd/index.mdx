# Product Requirements Documents (PRD)

Each feature in Lulu has a PRD that describes **what it is** (user-facing) and **how it is implemented** (technical approach). Use these to quickly understand scope and architecture.

## Design Diagrams

- **ERD** — [Data Model](/docs/system-design/data-model) — Database tables and relationships
- **Class diagram** — [Domain Model](/docs/system-design/domain-model) — Domain objects and services
