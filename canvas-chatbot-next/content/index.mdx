# Lulu System Documentation

Welcome to the system design and technology documentation for **Lulu** — the Canvas chatbot and study assistant.

## Why Read This

This documentation is structured for technical readers (employers, architects, contributors) who want to understand:

- **Design decisions** — Why we chose OpenRouter, Polar, Canvas tokens, and the AI SDK agent pattern
- **Architecture** — How the system is built: data model, chat flow, context management
- **Features** — What each feature does and how it is implemented (PRDs)
- **Trade-offs** — Explicit trade-offs and consequences of key decisions

## Contents

- [Design Principles](/docs/design-principles) — Principles, values, and constraints
- [ADR](/docs/adr) — Architecture Decision Records (context, decision, consequences)
- [PRD](/docs/prd) — Product Requirements Documents (what each feature is and how it works)
- [System Design](/docs/system-design) — Architecture, tech stack, data model, flows
- [API Overview](/docs/api/overview) — API design and endpoints
